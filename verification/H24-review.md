# H24 — بازبینی نسخه آزمایشی

وضعیت: در حال انجام. این گزارش شاهد خودکار و بازبینی کد است، نه تأیید بصری یا پذیرش مالک محصول.

نتیجهٔ به‌روز: build production با `npm run build` موفق شد؛ ۷۸ تست Backend روی PostgreSQL واقعی، ۴ تست Frontend، `npm run typecheck` و Ruff نیز موفق شدند. یک هشدار deprecation از وابستگی Starlette/httpx باقی است و در تست‌ها شکست ایجاد نکرد.

در اجرای محلی، ابتدا smoke test به دلیل عقب‌بودن migration دیتابیس توسعه با خطای ۵۰۰ روبه‌رو شد؛ پس از اجرای migration `c41e9a7b2d10` روی همان دیتابیس، smoke test موفق شد. مسیرهای عمومی و سلامت از proxy فرانت‌اند پاسخ ۲۰۰ و API خصوصی بدون نشست پاسخ ۴۰۱ دادند. مرورگر قابل‌کنترل در این نشست موجود نبود؛ بنابراین بازبینی بصری هنوز انجام نشده است.

## مسیر یکپارچه

`backend/tests/test_product_journey.py` سناریوی کامل را روی PostgreSQL واقعی از طریق API اجرا می‌کند: ساخت رویداد و انتساب دبیر، ثبت‌نام عمومی، اتصال حساب مهمان به همان پروفایل، رد سفارش در حضور نامشخص، ثبت حضور، سفارش، ارسال رسید رویدادی، تأیید رسید و شارژ کیف پول، تسویه، لغو رویداد و برگشت مبلغ. آزمون، یکتایی پروفایل، بدهی صفر، لغو هزینه‌ها، برگشت اعتبار و حذف رویداد لغوشده از صفحه عمومی را بررسی می‌کند.

## تطبیق PRD §۱۹

`acceptance_checklist.json` هر ۷۳ معیار PRD را به تسک اجرایی و شاهد موجود وصل می‌کند: ۳۸ معیار پیش‌تر «verified» بودند و ۳۵ معیار اکنون با مسیر تست به‌عنوان «implemented» ثبت شده‌اند. «implemented» به معنی پذیرش نهایی UI نیست. شواهد اصلی به تفکیک بخش:

- کاربران و حساب: `backend/tests/test_management.py` و `backend/tests/test_auth.py`؛ H04–H06.
- رویداد، مکان و صفحه عمومی: `backend/tests/test_events.py`، `backend/tests/test_public.py`، `backend/tests/test_event_import.py` و `backend/tests/test_cancellations.py`؛ H07، H08، H18، H23.
- مخاطب و ثبت‌نام: `backend/tests/test_guests.py`، `backend/tests/test_registrations.py`، `backend/tests/test_guest_import.py`؛ H09–H12، H22.
- حضور و مالی: `backend/tests/test_attendance.py`، `backend/tests/test_charges.py`، `backend/tests/test_settlements.py`، `backend/tests/test_payments.py` و `backend/tests/test_payment_review.py`؛ H13–H17.
- گزارش و خروجی: `backend/tests/test_reports.py`؛ H20–H21.
- پورتال مهمان: `backend/tests/test_guest_portal.py`؛ H19.

## RTL، موبایل و خطاها

بازبینی ایستا: `frontend/src/app/layout.tsx` زبان فارسی، `dir="rtl"` و فونت انجمن را تنظیم می‌کند. `frontend/src/app/globals.css` شکست چیدمان در ۸۵۰ و ۶۰۰ پیکسل، جدول با اسکرول افقی، و فرم تک‌ستونه در موبایل دارد. فرم‌های سناریو پیام خطا و قفل دکمه در جریان درخواست دارند؛ `frontend/tests/api.test.mjs` CSRF، refresh نشست و تبدیل خطای API را می‌سنجد. این‌ها جای مشاهده واقعی در مرورگر و دستگاه موبایل نیستند.
