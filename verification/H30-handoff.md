# H30 — وضعیت تحویل و انتشار

وضعیت: **نامزدِ قابل‌آماده‌سازی برای استقرار؛ منتشر نشده و پذیرفته نشده**. نسخهٔ کد Backend/Frontend: `0.1.0`؛ آخرین migration در کد: `c41e9a7b2d10`. tag یا شناسهٔ release منتشرشده وجود ندارد.

## تحویل موجود

- پیاده‌سازی Backend/Frontend و migrationها، راهنمای پروژه در `README.md`، راهنمای بهره‌بردار در `docs/operator-guide.md`، راهنمای استقرار و rollback در `deploy/README.md`.
- الگوهای systemd، Nginx/TLS/rate limit، env و مسیر uploads مشترک، و اسکریپت‌های بکاپ و آزمایش restore در `deploy/`.
- چک‌لیست معیارها در `acceptance_checklist.json` و برگهٔ تأیید مالک محصول/ورود داده در `verification/H29-acceptance.md`.
- بازبینی نهایی H30: کنترل ساخت و غیرفعال/فعال‌سازی دبیر و صدور رمز موقت حساب مهمان به پنل افزوده شد. APIهای متناظر قبلاً موجود و آزموده بودند. پس از تغییر، build production، typecheck، چهار تست Frontend، ۷۸ تست Backend روی PostgreSQL و Ruff موفق‌اند. هیچ مرور بصری انجام نشده است.
- smoke محلی پس از به‌روزرسانی migration دیتابیس توسعه موفق شد؛ مسیرهای عمومی ۲۰۰ و API خصوصی بدون نشست ۴۰۱ می‌دهند. این نتیجه جای smoke از origin عمومی روی سرور مقصد را نمی‌گیرد.

## دروازهٔ انتشار — همگی پیش از انتشار لازم‌اند

1. بستن پیش‌نیازهای H24 تا H29 با شاهد معتبر، از جمله مرور بصری و پذیرش مالک محصول روی دادهٔ نمایشی. build production با موفقیت انجام شده است.
2. مقصد Linux، دامنه و TLS، env و دیتابیس با دسترسی محدود، uploads خصوصی و قابل‌دوام؛ `nginx -t`، اعتبارسنجی unitها و health/readiness روی همان مقصد.
3. بکاپ هماهنگ دیتابیس و فایل‌ها، restore واقعی در دیتابیس موقت و تطبیق دفتر/مانده و فایل‌های ارجاع‌شده؛ ثبت نسخهٔ بکاپ و زمان نتیجه.
4. تست‌های ضروری و build روی release منتخب؛ smoke test از origin عمومی با `HASHTI_FRONTEND_ORIGIN=https://… node scripts/smoke.mjs` روی سرور (و `HASHTI_BACKEND_ORIGIN=http://127.0.0.1:8000` برای چک مستقیم محلی)، بررسی لاگ‌های systemd/Nginx بدون secret و کنترل ۴۰۱ برای API خصوصی.
5. تأیید صریح مالک محصول برای انتشار. فایل واقعی فقط پس از preview، بررسی خطاها و تأیید جداگانه وارد شود. `confirm` به‌معنی تأیید انتشار نیست.

## محدودیت و تصمیم فعلی

در این نشست سرور/دامنه و مجوز انتشار ارائه نشده است؛ build و آزمون‌های خودکار با درخواست جدید کاربر موفق شدند، اما پیش‌نمایش طبق درخواست قبلی اجرا نشد. بنابراین service restart، smoke محیط مقصد، بررسی لاگ production، backup/restore واقعی، import واقعی و انتشار انجام **نشده‌اند**. مانع‌ها پنهان نیستند و هیچ تاریخ انتشار قطعی از برآورد اولیهٔ ۱۰روزه استنباط نمی‌شود. در صورت آماده‌شدن زیرساخت و تأیید مالک، گام‌های بالا اجرا و زمان/نتیجه/نسخه در همین گزارش و ClickUp ثبت شود.
